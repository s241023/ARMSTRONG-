安全方針
まず読み取りだけを行います。書き込みテストは、JP60・VIA 0x000A・Base Layer・未使用matrixセルの確認がすべて成功した場合だけ手動で有効化できます。 本テストはEEPROM reset、bootloader jump、dynamic keymap reset、lighting write等のコマンドを送信しません。
Remap / VIA / QMK Toolbox / 他のキーボード設定ソフトは同時にJP60へ接続しないでください。

# kadaikennkyuu
更新の案がある際は教えてください。v0.8.3
<br>
仕様：メイン画面でキーログの読み取りを終わらせた後とリザルト画面のタイミングで「score」とタイピングすると開発者ツールが使えます。機能は詳細の数値確認、表形式でのコピーなど
<br>
<br>
現在経過
<br>
・入れ替え後キープレビュー完成
<br>
・メイン画面を軸にループできるように改善、キー配置をウェブ側で記録可能に変更
<br>
・手動で設定上のキー配置を変更する機能追加
<br>
・過去のキー配置を閲覧、適応(ウェブ内でのみ)できるようにする
<br>
<br>
